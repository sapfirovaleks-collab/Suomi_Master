# Suomi Master — Nationwide Outdoor & Service Ecosystem 🇫🇮🇳🇴

Единая цифровая платформа Финляндии и приграничной Норвегии для outdoor-активностей, трофейной рыбалки, грибной энциклопедии, аренды техники и безопасности.

## 🚀 Ключевые модули

* **⭐ ИИ-Радар рыбы & Прогноз клёва:** Точный расчёт клёва (Форель, Судак, Таймень, Палтус), выбор лучших приманок, тип водоема и стоимость лицензий (*kalastonhoitomaksu*, *viehelupa*).
* **🗺️ Общестрановая интерактивная карта:** Локации от Хельсинки и Саймы до Кокколы и фьорда Элвегорд (Норвегия).
* **🛠️ P2P Маркетплейс аренды:** Прокат лодок (Buster M), снастей для Норвегии, строительного оборудования и автоинструментов.
* **🚨 Модуль безопасности & SOS:** Автогенерация экстренных гео-сообщений для службы 112 и автоматический контроль правил *Jokamiehenoikeus*.
* **📷 Мобильный сканер:** Считывание QR-кодов лесных меток и оборудования прямо через камеру смартфона.
* **🍄 Энциклопедия дикоросов:** База съедобных грибов и ягод с защитой от ядовитых и ложных видов (горчаков).

## 🛠 Технологический стек

* **Backend:** Python 3.11+, FastAPI, SQLAlchemy (SQLite/PostgreSQL), Passlib (Bcrypt)
* **Frontend:** HTML5 MediaDevices API, Leaflet.js, CSS3
* **Production Ready:** Nginx, Systemd, SSL/Certbot, Docker-ready
